# Motor-Trail — Nature Assets Style Guide (v0.1)

## Intention

Coherent, original, stylized low-poly environment assets for a relaxed off-road exploration game with optional traversal challenges. Inspired by the **general artistic vocabulary** of [k0rveen's LowPoly Environment Pack](https://k0rveen.itch.io/lowpoly-environment-pack), not a reproduction of its meshes.

**Key visual rules**
- Bold, simple, asymmetrical silhouettes. Low polygon density with clearly readable facets.
- Flat shading with hard normals, no smoothing / subdivisions.
- Small number of opaque, matte solid-color PBR materials per object.
- No detailed photo textures, procedural noise maps, gloss, outlines, voxel blocks or toon post-processing.
- Natural but friendly color palette; greens are present in multiple controlled shades.
- Object alone, no base plate, no background, no shadows baked into the model.
- Metric unit dimensions and bottom-center origin; natural objects are approximately grounded.
- Place grass / ferns densely as instanced decorative props; add simplified physics collision only when needed.

## Asset family triangle budgets (future generations)

| Family | Suggested triangles per mesh (LOD0) |
| --- | ---: |
| Grass tuft, single small plant | 12–250 |
| Fern, shrub, smaller props | 50–800 |
| Boulders | 80–400 |
| Trees | 150–1,200 |

These are reference targets, not hard technical limits. Prototype assets are lighter than many of these budgets.

## Technical

- Export: binary `.glb` (glTF 2.0), independent file per asset, with embedded simple PBR material factors.
- Geometry: triangles, hard facet normals, no animation.
- glTF convention: Y-up; meshes were modeled Z-up and exported using trimesh's glTF axis conversion.
- Physics: no embedded colliders; assign gameplay-specific simplified colliders in engine.
- Terrain integration: pivot centered horizontally near the base. Some intentional irregularity is preserved.
- Low-density mesh is necessary but not sufficient for performance. Instance repeating props, tune LODs and culling, and use shared/imported materials in your engine as needed.
- Scale check: GLB units intended as meters. Verify import scale and orientation in your engine before mass placement.

## Suggested environment library roadmap

**V1 forest**: 15 deciduous trees, 12 conifers, 10 undergrowth variants, 15 rocks, 8 deadwood variants, plus LOD and collider variants.

**V2 terrain**: modular slopes, rocky steps, erosion cuts, riverbanks, mud, logs and passable obstacles built for vehicle traversal.

**V3 biomes**: alpine, temperate forest, autumn, dry canyon, coastal woodland. Prefer palette swaps and controlled variations to changing rendering style.
