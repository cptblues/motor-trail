# Mission A Implementation Plan

> Execute with focused workers, TDD and separate specification/quality review.

**Goal:** Protect the full 4x4 during rollovers, provide explicit opt-in tire
envelopes and usable, validated equipment foundations without changing base profiles.

**Architecture:** One dynamic chassis, a compound body shape, explicit base mass
properties, rigid equipment children with zero collider density. Native Rapier
remains the default wheel backend; the isolated experimental backend replaces
contact selection before the same single force pass. Serializable mount/loadout
data and Rapier mass-property composition remain independent of graphics nodes.

**Tech Stack:** Pinned Bevy 0.19, Rapier 0.33-alpha via bevy_rapier3d 0.35,
bevy_egui 0.42, existing serde; no new physics dependency or profile upgrade.

## Accepted Scope

User explicitly approved the composed-body/mount design and requested the tire
experiment disabled by default. A1 evidence is in docs/vehicle-collision-design.md.
The existing branch and documentation edits are retained. No commit/push/merge
is required. Parent coordinates Cargo because this Windows checkout shares a
large target cache on D:; workers request test runs instead of competing linkers.
